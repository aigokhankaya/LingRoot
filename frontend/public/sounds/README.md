# 🔊 Sound Effects

Bu klasör gamification ses efektlerini barındırır.

## Gerekli Dosyalar

Aşağıdaki ses dosyalarını bu klasöre ekleyin:

| Dosya | Kullanım | Önerilen Süre |
|-------|----------|---------------|
| `xp-gain.mp3` | XP kazanıldığında | 0.5-1 saniye |
| `level-up.mp3` | Level atlandığında | 1-2 saniye |
| `achievement.mp3` | Rozet kazanıldığında | 1-2 saniye |
| `streak.mp3` | Streak milestone'unda | 1 saniye |
| `click.mp3` | Buton tıklaması | 0.2 saniye |
| `success.mp3` | Başarılı işlem | 0.5 saniye |
| `error.mp3` | Hata durumu | 0.5 saniye |

## Ücretsiz Ses Kaynakları

- [Freesound.org](https://freesound.org/)
- [Mixkit](https://mixkit.co/free-sound-effects/)
- [Pixabay Sounds](https://pixabay.com/sound-effects/)
- [ZapSplat](https://www.zapsplat.com/)

## Önerilen Sesler

**XP Gain:** Coin/gem toplama sesi
**Level Up:** Fanfare/victory jingle
**Achievement:** Medal/badge unlock sesi
**Streak:** Fire/flame crackling
**Click:** Soft UI click
**Success:** Positive chime
**Error:** Negative buzz

## Dosya Formatı

- Format: MP3 (geniş uyumluluk için)
- Bitrate: 128kbps minimum
- Mono veya Stereo
- Normalize edilmiş ses seviyesi
