### Hata Ayıklama Seansı

**Junior Dev:** I can't figure out why the API is returning a 401 error. The token looks valid.

**Senior Dev:** Let's check the server logs first. Can you pull up the latest entries?

**Junior Dev:** Here they are. I see "Token expired" in the logs.

**Senior Dev:** When was the token generated?

**Junior Dev:** About two hours ago.

**Senior Dev:** That's the issue. Our tokens expire after one hour. You need to implement the refresh token logic.

**Junior Dev:** I see. How should I handle the token refresh?

**Senior Dev:** Check for 401 responses, then call the refresh endpoint before retrying the original request.

**Junior Dev:** Got it. I'll implement that and add tests for the refresh flow.
