## 4. Icerik Sablonlari

### 4.1 Instagram Carousel: Gunun 5 Kelimesi

**Slide 1 (Kapak):**
```
BUGUN OGRENECEGM
5 KELIME

[Tema: Isbis Disi Ingiizcesi]

@lingroot.app
```

**Slide 2-6 (Kelimeler):**
```
1. DEADLINE
/ˈdedlaɪn/

Anlami: Son teslim tarihi

Ornek:
"The deadline is Friday."
```

**Slide 7 (CTA):**
```
Bu kelimeleri LingRoot'ta
pratik et!

Link bio'da

Kaydet & Paylas
```

### 4.2 Instagram Reels: Telaffuz

**Format:** 15-30 saniye

**Script:**
```
[Hook - 3 sn]
"Bu kelimeyi herkes yanlis soyluyor..."

[Yanlis telaffuz - 3 sn]
"Schedule - Ske-dule degil!"

[Dogru telaffuz - 5 sn]
"Amerikan: /ˈskedʒuːl/"
"Ingiliz: /ˈʃedjuːl/"

[CTA - 3 sn]
"Daha fazlasi icin takip et!"
```

### 4.3 TikTok: Trend Audio + Egitim

**Format:** 15-30 saniye, trend sound

**Yapi:**
```
[Trend transition ile basla]
[Text overlay: "POV: Ingilizce ogreniyorsun"]
[Gorsel 1: Zorluk]
[Gorsel 2: LingRoot cozumu]
[CTA: Bio'daki linke tiklayın]
```

### 4.4 Twitter Thread: Dil Ogrenme Tip

**Thread (5 tweet):**
```
Tweet 1:
Ingilizce dinleme becerinizi gelistirmek icin 5 kanıtlanmis yontem:

(Thread)

Tweet 2:
1. Comprehensible Input

Seviyenizin biraz ustunde icerik dinleyin. Stephen Krashen'in i+1 teorisi bunu destekler.

LingRoot bunu otomatik yapiyor.

Tweet 3:
2. Active Listening

Pasif dinleme yerine not alin, kelime cikarın, tekrar dinleyin.

Tweet 4:
3. Shadowing

Duydugunuzu hemen tekrar edin. Telaffuz ve akici konusma icin harika.

Tweet 5:
4. Consistent Practice

Gunde 15 dakika > haftada 2 saat

LingRoot streak ozelligi ile motivasyonunuzu koruyun.

Link: [bio]
```
