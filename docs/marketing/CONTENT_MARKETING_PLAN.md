## 5. SEO Optimizasyonu

### 5.1 On-Page SEO Checklist

- [ ] Title tag: Keyword + magnet kelime (60 karakter)
- [ ] Meta description: Keyword + CTA (155 karakter)
- [ ] H1: Ana keyword icermeli
- [ ] H2/H3: Secondary keywords
- [ ] URL: Kisa, keyword iceren (/cefr-seviyeleri-rehber)
- [ ] Image alt text: Descriptive + keyword
- [ ] Internal linking: En az 3 iliskili sayfa
- [ ] External linking: En az 2 authority kaynak
- [ ] Schema markup: Article, FAQ, HowTo
- [ ] Mobile responsive: Test edilmis
- [ ] Page speed: 3 saniye altinda

### 5.2 Internal Linking Stratejisi

**Link Hiyerarsisi:**
```
Pillar Page
    |
    +-- Blog Post 1
    +-- Blog Post 2
    +-- Glossary Entry 1
    +-- Glossary Entry 2
```

**Linking Kurallari:**
- Her blog post en az 1 pillar page'e link vermeli
- Glossary'ler iliskili blog postlara link vermeli
- Yeni icerik eski iceriklere link vermeli

### 5.3 Programmatic SEO

**Otomatik Olusturulacak Sayfalar:**

| Sablon | Ornek | Tahmini Sayfa |
|--------|-------|---------------|
| CEFR [Seviye] Kelime Listesi | "CEFR B1 Kelime Listesi" | 6 |
| [Sektor] Ingilizcesi | "IT Sektoru Ingilizcesi" | 20 |
| [Konu] Ingilizce Kelimeler | "Uzay Ingilizce Kelimeler" | 50 |
| Ingilizce [Konu] Podcast | "Ingilizce Tarih Podcast" | 30 |

## 8. Icerik Uretim Sureci

### 8.1 Workflow

```
1. Keyword Research (Pazartesi)
   - SEMrush/Ahrefs analizi
   - Rekabet analizi
   - Topic onceliklendirme

2. Outline Olusturma (Sali)
   - H2/H3 yapisi
   - Kaynak arastirmasi
   - CTA planlama

3. Yazim (Carsamba-Persembe)
   - Ilk draft
   - Duzeltme
   - SEO optimizasyonu

4. Gorseller (Cuma)
   - Featured image
   - Infografik (gerekirse)
   - Screenshot/diagram

5. Yayin ve Dagitim (Pazartesi)
   - Blog'a yukle
   - Sosyal medya planlama
   - Newsletter ekleme
```

### 8.2 Kalite Kontrol Checklist

- [ ] Keyword yogunlugu: %1-2
- [ ] Okuma seviyesi: Uygun (Grade 8-10)
- [ ] Gramer/imla kontrolu
- [ ] Fact-checking yapildi
- [ ] Gorseller optimize edildi
- [ ] Internal link eklendi
- [ ] CTA yerlestirildi
- [ ] Mobile preview kontrol
