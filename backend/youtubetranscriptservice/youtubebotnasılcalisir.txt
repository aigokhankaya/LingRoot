1. Gerekli Kütüphaneleri Yükle
Ana proje klasöründe (LingRoot) terminali aç:

cd C:\Users\USER\Documents\GitHub\LingRoot

pip install -r backend/youtubetranscriptservice/requirements.txt


Eğer Playwright ilk defa kuruluyorsa, tarayıcıları da yüklemen gerekir:
python -m playwright install


2. Servisi Başlat
yine root klasörde 

uvicorn backend.youtubetranscriptservice.main:app --host 0.0.0.0 --port 8000


3. Servisin Çalıştığını Kontrol Et
Tarayıcıdan şu adrese git:
http://localhost:8000/docs


4. Test Et (Opsiyonel)
Bir YouTube linkiyle transcript almak için Postman veya terminalden şu şekilde test edebilirsin:
curl -X POST "http://localhost:8000/scrape-transcript" -H "Content-Type: application/json" -d "{\"url\": \"https://www.youtube.com/watch?v=TkZff6wRpu8\"}"
