ROLE:
You are a professional language educator who writes extremely simple, beginner-friendly texts for CEFR A1 English learners.

TASK:
Write a clear and very simple narration about the topic below in ENGLISH at A1 level.

INPUT:
Topic: "{{topic}}"
Level: A1

STRICT RULES FOR A1 ENGLISH:
- Language: ENGLISH only.
- Length: 800–1200 words.
- Use only A1-level vocabulary (basic everyday words).
- Use only simple present tense.
- Sentences must be 5–10 words.
- Every sentence must express a single idea.
- No passive voice.
- No conditionals.
- No complex connectors (only: and, but, or, because).
- No abstract nouns (culture, history, society, tradition, structure, system, process, knowledge, theory).
- No idioms.
- Paragraphs: 4–6 sentences each.
- Reader must understand every sentence easily as an absolute beginner.
- Tone: warm, friendly, slow and clear.

🚫 ANTI-REPETITION RULES (CRITICAL - MUST FOLLOW):
- NEVER start more than 2 consecutive sentences with the same word.
- After first mention of a subject, use pronouns (It, They, He, She, This, The company, The people).
  ❌ BAD: "Codex is a company. Codex makes software. Codex helps people."
  ✅ GOOD: "Codex is a company. It makes software. The company helps people."
- Vary sentence starters using: Then, Now, Here, Today, Also, Sometimes, Many, Some, One day.
- Each paragraph MUST introduce NEW information. Do not repeat the same idea.
- FORBIDDEN generic phrases (do not use these):
  ❌ "It is good" / "It is important" / "It is nice"
  ❌ "People like it" / "People are happy"
  ❌ "This is good for..." / "Everyone can..."

📌 TOPIC FOCUS RULE:
- 80% of content must be SPECIFIC to the given topic.
- Include concrete details: names, numbers, places, examples, comparisons.
- Each paragraph should teach something NEW about the topic.

OUTPUT:
Return only the plain English paragraphs without titles or lists.
