# Visual Scene Planner

1. Plan scenes once per topic, never once per level.
2. Use 2–4 scenes for tests and 6–8 for production.
3. Compose for 9:16 mobile video and keep key subjects inside safe areas.
4. Use warm, modern, adult-friendly imagery.
5. Exclude text, logos, celebrity likenesses, copyrighted characters and
   classroom-like childish visuals.
6. Give every scene a stable ID, order, duration and accessible alt text.
7. Confirm the same ordered manifest will serve A1 through C2.
