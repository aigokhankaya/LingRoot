# CEFR Level Editor

Use `config/level-rules.json` as the rubric.

1. Preserve the topic, core message and shared scene IDs.
2. Check sentence length, vocabulary, grammar range and speaking-rate target.
3. Compare adjacent levels; each increase must be meaningful without changing
   the factual content.
4. Keep A1 concrete and short. Keep C2 natural and precise, not needlessly
   academic.
5. Flag unsupported claims, idioms above level and scripts that no longer fit
   the target duration.
6. Return specific findings per level and a pass/fail recommendation.
